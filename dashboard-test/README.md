# Dashboard tests

```bash
node --test dashboard-test/data.test.mjs         # data functions of the dashboard, no dependencies
```

`fixtures/<scenario>/` holds `latest.json` and `history.json` in the format written by `scripts/report/build_report.py`
(`scripts/report/schema.md`). To look at a scenario, copy it next to the site and serve the folder:

```bash
cp -r dashboard /tmp/site && cp -r dashboard-test/fixtures/mixed /tmp/site/data
python3 -m http.server -d /tmp/site 8080
```

| Scenario | Content |
|----------|---------|
| `real-fork` | Real data: the nightly runs of a fork between 2026-10-17 and 2026-10-25, generated from the Actions API. Every run fails while setting up k3s. |
| `mixed`, `healthy`, `incomplete-stale` | **Synthetic**, generated by the report generator from made-up runs and JUnit files, to exercise failed, flaky, incomplete and stale builds. The numbers are not results of this project. |
| `empty` | A first deployment without any run. |

The pages were also checked with axe-core (WCAG 2.1 AA, 0 violations on every scenario in light and dark), with
reduced motion, from a sub path (`/litmus-e2e/`) and with malformed or hostile data (names and messages are rendered
as text only).
