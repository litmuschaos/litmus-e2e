# Nightly dashboard

A static site, plain HTML, CSS and ES modules without a build step or dependencies, so it can be published as it is
to GitHub Pages. All URLs are relative and the routes use the URL hash, it works from any path (`/litmus-e2e/`).

| File | Purpose |
|------|---------|
| `index.html`, `assets/styles.css` | Shell, design tokens (light, dark and the validated status and series colors) |
| `assets/js/data.js` | Loading, validation and the derived numbers (pure functions, tested in `dashboard-test/`) |
| `assets/js/charts.js` | SVG ring, stacked bar, timeline and line chart |
| `assets/js/views/` | Overview, experiments, frontend, history and data pages |
| `data/` | Generated by `scripts/report/build_report.py`, not committed |

Text from the results is only ever inserted with `textContent`, links are limited to `https`, status colors always come
with an icon and a label, motion is turned off with `prefers-reduced-motion`, and every chart has a table view.
